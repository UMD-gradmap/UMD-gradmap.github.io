#### Welcome to GRAD-MAP Code Lab! This is a platform designed for *anyone* to learn scientific Python. We hope to support:

* #### Beginners who may have zero Python experience
* #### Intermediate or advanced programmers who want to learn specific, research-grade techniques in physics or astronomy
* #### Instructors who wish to use or adapt our lectures for the classroom
* #### GRAD-MAP Winter Workshop attendees or Summer Scholars that want to refresh or hone their skills

#### Code Lab includes a GitHub repository with Jupyter notebooks, Python scripts, and data, which is everything you need to start coding. Additionally, we will provide video lectures in the form of a YouTube playlist for our base notebooks (lectures 0-5). 

#### **Code Lab will be released to the public in Spring 2027. We hope to see you back here soon!**
